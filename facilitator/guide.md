## 每場的流程

1. 開場 3 到 5 分鐘：確認每個人打得開連結、麥克風正常。**開連結、麥克風、提問每場至少耗 3 到 5 分鐘，時間表不留零緩衝。**
2. 每個練習：講師示範（學員只看，不跟著打）→ 切到自己視窗做 → 進度投票 → 下一個。
3. 重複的程式碼用貼的，現場只打最關鍵的 3 到 5 行。
4. 卡住的人拉進分組討論室，不拖慢全班；**絕不在共享畫面上除錯**。

## 共享前檢查表

- [ ] 只分享單一視窗，關閉通知
- [ ] 螢幕 1920×1080、縮放 125 到 150%、編輯器字體 22 到 24px、淺色高對比
- [ ] 中文字型用微軟正黑體或 Noto Sans TC；一個畫面不超過約 25 行
- [ ] 專用瀏覽器設定檔；聊天室不上畫面；不出現內部網址、權杖、客戶資料
- [ ] 進度表已開；示範影片已預錄；協助者已就位（本場需要時，見下）
- [ ] 示範頁用 `npm run build` 產生，已開好；← → 可以切換段落

## 連結與存檔的注意事項（實測）

- play.vuejs.org 的連結**網址 # 後面就是全部內容**。在同一個分頁換一個只有 # 後面不同的連結，頁面**不會重新載入內容**。示範頁的連結一律在新分頁開啟；若學員反映「點了連結還是上一題」，請他按 F5 重新整理。
- 「複製網址列 = 存檔」。沒複製就關分頁，內容會遺失。
- 長網址在聊天室可能被截斷，不要用聊天室傳連結，用示範頁的連結。
- 錯誤訊息出現在預覽區**下方**的方框：橘色是警告，紅色是錯誤。

## 什麼時候需要協助者

符合任一條就需要：

1. 學員要現場跑程式，且人數超過 5 人。
2. 場次是環境安裝（安裝診所）。
3. 計時的結業檢查（S6、S8）。

只有示範或導讀的場次、或 5 人以下，不需要。理由：主講者一旦停下來幫某個人除錯，其他人就整個停下來。每個卡住的人約耗 3 到 5 分鐘，**這個數字要在試行時實測，不先當作事實**。

協助者在分組討論室或私訊解卡、管進度表與聊天室、掌控時間。

**沒有協助者時**：每一步都附「卡住了」連結，直接跳到該步驟的解答；問題留到課後 10 分鐘答疑；每次練習後做進度投票；用預錄示範。

## 示範預錄

試行時先預錄示範影片，直播錄影當備援。預錄完請把每一步的時間點記在進度表，之後用 `ffmpeg -ss … -to … -c copy` 剪成每步 3 到 5 分鐘（見 PLAN 第 7 節）。
