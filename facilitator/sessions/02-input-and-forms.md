## 講稿重點

- `v-model` 用「打字→資料變，資料變→畫面變」雙向圖解，不講語法糖拆解。
- `ref` vs `reactive`：一張對照表就好，不討論何時選哪個。今天的規則是「一個欄位用 `ref`，多欄位用 `reactive`」。
- 練習 3 示範時先不加 `.prevent`，按送出讓整頁重新載入、資料消失，再加上。
- 錯誤訊息段：示範時**自己故意打錯**，並大聲念出方法（第一行→找框起來的名字→搜尋）。三種錯誤都已在 play.vuejs.org 實測，訊息文字與學員畫面一致。
- 練習 3 的「空白不能送出」是之後 S6 結業檢查要用的，請強調。

## 常見卡點

| 現象 | 原因 | 怎麼帶 |
| --- | --- | --- |
| 輸入框打字畫面沒變 | `v-model` 寫在別的元素上，或綁了 script 沒有的名字 | 看有沒有橘色警告 |
| 勾選框變成字串 | 用了 `value` 而不是 `v-model` | 勾選框就是 `v-model`，值是 true/false |
| `form.title.value` 是 undefined | 把 `reactive` 當 `ref` | reactive 不用 `.value` |
| `form = {...}` 報錯：Assignment to constant variable | `const` 不能重新指定 | 改欄位逐個賦值，不要換掉整個物件 |
| 送出後整頁清空 | 沒加 `.prevent` | 看事件修飾詞 |
| 全空白也能送出 | 沒用 `.trim()` | 練習 3 題目寫了 |
