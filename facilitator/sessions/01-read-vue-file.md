## 講稿重點

- 開場先講「你不用背，今天只要能看懂一個 `.vue` 檔」。
- 看 `.vue` 檔那一段只問：「資料在哪？畫面在哪？」不解釋每一行。
- 練習 2 示範時故意先寫 `const students = 12`，按按鈕數字不動，再改成 `ref`。讓學員自己看到「為什麼要 ref」。
- 練習 3 的 `.value`：一句話——script 要 `.value`，template 不用。不講 Proxy、不講響應式原理（「Vue 為什麼可以直接改狀態」刻意不教）。

## 常見卡點

| 現象 | 原因 | 怎麼帶 |
| --- | --- | --- |
| 畫面空白、橘色警告說某個名字沒定義 | `import { ref } from 'vue'` 忘了，或名字拼錯 | 看預覽區下方的方框，找引號裡的名字 |
| 人數顯示空白 | template 寫了 `students.value`（template 不用寫） | 回到「script 要、template 不用」 |
| 按鈕按了數字不動 | 還是 `const`，沒用 `ref` | 對照練習 2 示範 |
| 按減一變成 -1 | 忘了判斷 `> 0` | 練習 3 題目最後一行 |
| 點了連結還是上一題的內容 | 在同一分頁只換 # 後面，頁面不重載 | F5，或在新分頁開 |

## 通過訊號

每個練習做完後，畫面要和示範頁的描述一致。進度表綠燈 = 畫面對了。
